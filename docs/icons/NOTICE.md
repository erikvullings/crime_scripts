# PAX built-in icon catalogue

All icons in this directory are original PAX Crime Scripting repository artwork or user-contributed artwork authorized for publication under the repository MIT license. The eight user-contributed source SVGs (biogas-digester, company-registry-document, dangerous-dog, dog, freight-truck, hospital, pitbull, and shipping-container) are also retained in `packages/gui/src/assets/icons/`. No Noun Project or other third-party artwork is included in this catalogue.

Every SVG was normalized and optimized with SVGO 4.0.0 using `packages/gui/svgo.config.mjs`. Machine-readable provenance is recorded in `catalogue.json`.
